# Cooperacai: site de uma cooperativa de açaí

Site de página única para uma cooperativa de produtores de açaí das ilhas do Pará, em parceria com a Secretaria Municipal de Agricultura. É um projeto de front-end em um único arquivo (`index.html`), sem dependências nem etapa de build.

## Seções

Início · Cooperativa · Cadeia (as cinco etapas, do fruto ao consumidor) · Safra (gráfico por mês) · Secretaria · Associe-se · Contato

## Recursos

- Tema claro e escuro, que segue a preferência do sistema.
- Layout adaptado a diferentes tamanhos de tela.
- Animação em `canvas` no topo da página e gráfico sazonal da safra gerado em JavaScript.
- Respeita a preferência por menos movimento (`prefers-reduced-motion`).
- Formulário de contato com validação no navegador.
- Atributos ARIA no menu e no gráfico, para leitores de tela.
- Fontes: Gloock, Figtree e IBM Plex Mono (Google Fonts).

## Como rodar

Abra o `index.html` no navegador.

## Observação

Os dados de contato do site (como o telefone) são de exemplo.
